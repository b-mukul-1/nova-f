# nova-f

## NovaTech Solutions — Bold Technology Experience

A bold, dark-first, technology-focused multi-page digital experience for **NovaTech Solutions**, engineered in React, TypeScript, and modern Vanilla CSS.

### Key Features
- **Atmospheric Blue Horizon:** Radiant electric blue planetary curvature arc illuminating the deep navy space backdrop (`#071426`, `#040D1A`).
- **Connected Geodesic Network:** Luminous cyan wireframe sphere and telemetry nodes representing distributed enterprise systems.
- **Controlled Architectural Geometry:** Thin technical gridlines (`#243A55`), high-contrast white headings, and electric blue micro-accents.
- **Selective Contrast:** Clean light practice area section (`#F1F5F9`) creating rhythm between deep cosmos and architectural clarity.
- **Custom Brand Identity:** Scalable SVG vector mark with illuminated nodes in `Logo.tsx` and local `favicon.svg`.

### Implemented Routes
- `/` — Homepage (Hero, metrics bar, geodesic showcase, capabilities, 4-stage approach timeline, modular systems feature, 5 pillars, fictional case study demo, FAQ accordion, final CTA, watermark footer)
- `/about` — About NovaTech (Manifesto, zero-debt principles, 6 operating axioms, bi-weekly sprint cadence)
- `/services` — Practice Areas Catalog (Technology Strategy, Digital Product Development, Web & Software Solutions, Systems Integration)
- `/services/:slug` — Dedicated Service Detail Template (Problem analysis, deliverables checklist, 4-phase execution roadmap)
- `/contact` — Consultation Request (Direct channels, interactive scoping form, multi-select service pills, timeline selection, validation, and success state)
- `/privacy` — Privacy Policy & Data Governance (Prominent legal placeholder banner)

### Development & Commands
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run Oxlint validation
npm run lint

# Build for production
npm run build

# Preview production build
npm run preview
```
